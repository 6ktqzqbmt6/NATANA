# 구현 검증 기록

## 통과한 검증

- `npm ci`: 잠금 파일 기반 의존성 설치
- `npm test`: 2개 파일, 16개 테스트
- `npm run build`: Next.js 프로덕션 빌드와 타입 검사
- `npm run typecheck`: 독립 TypeScript 검사
- `npm audit --omit=dev`: 알려진 프로덕션 의존성 취약점 0개
- 프로덕션 출력의 파일 추적에 7개 역할 지침 포함 확인

테스트는 승인 이메일 정확 일치, Google 이메일 확인 상태, 요청 출처, 역할 및 메시지 검증, 본문 크기, 요청 빈도, 비로그인·권한 회수 사용자 차단, API 키 부재, 역할 프롬프트 연결, 오류 정보 비노출, 답변 길이 제한 안내를 다룹니다.

## Chromium에서 확인한 동작

실제 프로덕션 서버를 실행하고, 테스트 전용 임시 비밀로 발급한 세션 및 모의 AI 응답을 사용했습니다. 인증을 우회하는 기능은 애플리케이션에 추가하지 않았습니다.

- 설정 미완료 시 로그인 안내 화면 표시
- 비로그인 페이지 리디렉션 및 채팅 API 거부
- Google 제공자·CSRF 엔드포인트 응답
- 승인 세션의 접근과 미승인 세션의 거부
- 잘못된 출처 차단, API 키 부재 시 설정 오류 응답
- 7개 역할 선택 및 역할별 대화 분리
- 모의 답변 표시, 새 대화 취소·초기화
- 요청 실패 시 질문 복원
- 모바일 메뉴와 가로 넘침 없음
- 브라우저 런타임 오류 없음

화면 기록: [데스크톱](screenshots/studio-desktop.png), [모바일](screenshots/studio-mobile.png), [로그인](screenshots/login.png). 화면의 이메일은 테스트용 예시입니다.

## 아직 실행하지 않은 검증

실제 Google 계정 OAuth 왕복 로그인, 실제 OpenAI 답변, Vercel 배포는 해당 계정의 설정값이 없어 실행하지 않았습니다. [배포 안내](DEPLOYMENT.md)에 따라 설정하고 실제 계정으로 최종 점검해야 합니다. 위 모의 검증은 외부 서비스 연결 완료를 의미하지 않습니다.
